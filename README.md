# Flask Tasks CRUD API

REST API built with Flask to manage tasks using full CRUD operations.

## Features
- Create tasks
- List tasks
- Delete tasks
- SQLite database with SQLAlchemy
- Modular Flask architecture

pip install -r requirements.txt
